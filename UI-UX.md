# Madhuram Honey — V1 UI/UX Specification

## 1. Design Goal

Create a premium, warm and trustworthy honey-brand website.

The UI should communicate:
- Natural
- Pure
- Premium
- Carefully sourced
- Local
- Human
- Trustworthy

The design should feel intentional and calm rather than overly decorative.

## 2. Visual System

### Colors

**Deep Forest Green**
- Primary brand color
- Dark sections
- Process
- Final CTA
- Footer
- Important headings

**Warm Cream**
- Main backgrounds
- Hero
- Story
- Product areas

**Honey Gold / Amber**
- Active navigation underline
- Labels
- Number circles
- Primary CTA
- Hover states

**White**
- Cards
- Clean content areas

Do not introduce unrelated colors.

## 3. Typography

Use two complementary styles.

### Display
Premium serif for:
- Hero heading
- Section headings
- Product heading
- Story heading
- CTA heading

### Body
Clean sans-serif for:
- Navigation
- Paragraphs
- Buttons
- Cards
- FAQ
- Contact

## 4. Global Layout

Desktop:
- Centered max-width container
- Generous horizontal spacing
- Controlled section spacing

Mobile:
- Smaller horizontal padding
- Reduced vertical spacing
- Natural stacking
- No horizontal overflow
- Touch-friendly buttons

## 11. Trust / Reviews

Never invent customer reviews.

If real reviews exist:

```text

Name
★★★★★
```

Maximum three cards initially.

Without real reviews, use trust messaging.

## 16. Buttons

Primary:
- Honey gold
- Dark text
- Rounded
- Medium-bold
- Subtle hover lift/shadow

Secondary:
- Outline
- Transparent
- Good contrast

WhatsApp CTA:
- WhatsApp icon
- Clear order wording

## 17. Cards

- White/light background
- Soft border
- Small/medium radius
- Very subtle shadow
- Comfortable padding

Avoid strong glassmorphism, huge shadows, excessive gradients, and childish over-rounding.

## 18. Icons

Use one consistent icon family.

Suggested:
- Purity: sparkle/natural
- Freshness: clock/leaf
- Packaging: package/jar
- Local: location
- Phone: phone
- WhatsApp: message/WhatsApp
- Instagram: Instagram
- Location: map pin

Keep icon size and stroke weight consistent.

## 20. Image Optimization

- Compress large files
- Prefer WebP/AVIF where suitable
- Keep PNG when transparency is needed
- Preserve product proportions
- Add alt text

Suggested alt text:
- Product: `Madhuram Honey 750 ml bottle`
- Story: `Madhuram Honey beekeeping and honey harvesting`
- Logo: `Madhuram Honey`

## 21. Responsive Breakpoints

Suggested:
- Mobile: `< 768px`
- Tablet: `768px – 1023px`
- Desktop: `≥ 1024px`

Use flexible grids, flexbox, `clamp()`, and max-width containers rather than hardcoded layouts.

## 22. Animation

Allowed:
- Subtle section reveal
- Button hover
- Card hover
- Process hover
- FAQ transition
- Mobile menu transition

Avoid:
- Excessive parallax
- Constant floating objects
- Large spinning animations
- Distracting bee animations
- Long loading animations

## 23. Accessibility

Required:
- Semantic HTML
- Keyboard navigation
- Visible focus states
- Accessible labels
- Alt text
- Good contrast
- Comfortable touch targets
- Keyboard-accessible FAQ
- Accessible mobile menu
